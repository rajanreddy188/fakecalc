# fakecalc v3

Rebuilt against the supplied iPhone Calculator screen recording.

Files:
- index.html
- manifest.webmanifest
- icon-180.png

No build step. Upload these files to the root of the GitHub Pages repository.

Notable changes in v3:
- Exact 5x4 key arrangement from the recording
- Backspace icon remains in the first position
- AC changes to C while a calculation is active
- In-progress calculations are shown inline in the large display
- Completed expression appears in gray above the result
- Quick touch-down/touch-up highlight animation modeled after the supplied recording
- Different pressed colors for digit/function/operator keys
- Selected operator state
- Updated spacing, sizing, display typography, and toolbar icons
- Repeated equals behavior and local history
